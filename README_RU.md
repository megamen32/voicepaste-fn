# VoicePaste

Нажмите горячую клавишу, скажите фразу, отпустите — VoicePaste вставит транскрипцию в активное поле.

## Скачать

Откройте [релиз v2.0.0](https://github.com/megamen32/voicepaste-fn/releases/tag/v2.0.0) и скачайте установщик для macOS, Windows или Linux.

На macOS после первого запуска разрешите микрофон и Accessibility. В настройках укажите Whisper/OpenAI-compatible endpoint и API key.

## Тестирование

- macOS: Rust/Tauri production canary — PASS.
- Windows: не тестировано в этой сессии — удалённый сеанс недоступен.
- Mac Mini: не тестировано в этой сессии — SSH недоступен.

Подробный код и исходники: [VoicePasteTauri](VoicePasteTauri/).
