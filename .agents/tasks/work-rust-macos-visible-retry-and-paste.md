# Задача: Rust VoicePaste — видимый статус, управляемый retry и реальная вставка

## Цель

Свести текущую Rust-ветку в `main`; сделать в macOS Rust-клиенте явные состояния
«Запись» и «Обработка», закрываемую ошибку с выбором повторной попытки
`Удалённо / Системный / Локально`; подтвердить свежей сборкой на Mac Mini вставку
в Codex и, если установлен, Zed.

## Canary

В свежем Rust `.app` на `roomhacker@192.168.2.4` завершённая тестовая
транскрипция вставляется в фокусное поле Codex. Если Zed установлен — тот же
путь подтверждён и в Zed. Ошибка транскрипции остаётся видимой до «Закрыть» и
позволяет выбрать конкретный движок для повтора.

## Scope

- Включено: Rust overlay/retry/paste и интеграция ветки в `main`.
- Исключено (P2): постоянное хранение аудиозаписей и меню аудиоархива.

## Решение

Минимальное: сохранить временный WAV только для retry, добавить явный dismiss и
одноразовый выбор движка без изменения сохранённых пользовательских настроек.
