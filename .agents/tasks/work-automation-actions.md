# Универсальные действия после распознавания

Статус: готово

## Результат

Одно настраиваемое действие после распознавания: запуск программы с безопасными
аргументами или запись текста в файл. Триггером служит ключевое слово с
позицией поиска либо `Fn + Control` на macOS. Вебхук реализуется обычной
командой `curl`, а не отдельной интеграцией.

## Короткий пользовательский canary

Настроить запись в временный файл, произнести ключевое слово и текст, затем
получить в файле только остаток фразы. Для `Fn + Control` тот же файл получает
всю фразу без вставки в активное приложение.

## Границы MVP

- одно активное действие, чтобы не было неясного порядка нескольких команд;
- прямой запуск executable + аргументы по строкам, без shell-интерпретации;
- `curl` и любые локальные CLI работают через тот же интерфейс;
- файл можно дописывать или перезаписывать;
- токены не возвращаются из настроек в UI.

## Решение

Это кроссплатформеннее специализированного webhook: приложение передаёт
текст как stdin и подставляет `{text}`, `{text_json}` или `{text_url}` в
аргументы, а ОС запускает выбранную программу напрямую.

## Проверка

- Rust: `cargo test --lib` — 86 тестов прошли, включая keyword-позиции,
  файл, stdin процесса, payload `Fn + Control` и требования разрешений.
- Swift: `swift test` — 17 тестов прошли, включая Fn+Control в обоих порядках
  нажатия и возврат к обычному Fn после сочетания.
- UI: `node --check VoicePasteTauri/src/settings.js` и `git diff --check`.
- macOS bundle: в `target/release/bundle/macos/VoicePaste.app` есть
  `modifier_monitor` с `fn_control`; bundle повторно подписан и прошёл
  `codesign --verify --deep --strict`.
