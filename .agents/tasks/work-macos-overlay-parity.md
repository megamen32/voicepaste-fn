# Задача: компактный macOS overlay Rust

Статус: готово

## Цель

Сделать обычные состояния Rust/Tauri overlay такими же компактными и
ненавязчивыми, как у Swift-приложения, сохранив явные кнопки «Закрыть» и выбор
движка при ошибке.

## Canary

Свежий workspace `.app` на macOS показывает `58×38` индикатор при записи и
обработке, не перехватывает ввод, а короткий результат занимает только нужную
ширину. Ошибка остаётся отдельной управляемой карточкой.

## Решение

Не заменять Tauri на новый native UI: привести размеры и визуальную грамматику
существующего overlay к Swift (`58×38`, точка/спиннер, динамичный текст),
потому что это самый короткий обратимый путь без затрагивания hotkey/paste/STT.

## Реализация

- `recording` и `waiting`: `58×38`, только пульсирующая точка или спиннер;
- preview: `120–500×38`, либо `×72` только для длинного текста;
- retry: `360×118`, ошибка вставки: `320×92`;
- Computer Use canary ожидает новые компактные размеры, а не старые `148×48` и
  `360×100`.
- Для параллельной проверки при запущенной пользовательской версии canary
  поддерживает временный `F13` вместо `Fn`; это не меняет пользовательскую
  конфигурацию.
