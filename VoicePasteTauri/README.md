# VoicePaste

Voice transcription in any app: press the hotkey, speak, release — the text is inserted into the active field.

## Install

Open the [v2.0.0 release](https://github.com/megamen32/voicepaste-fn/releases/tag/v2.0.0) and download the installer for your system:

- macOS — `.dmg`
- Windows — `.msi` or `.exe`
- Linux — `.deb` or `.AppImage`

On macOS, allow Microphone and Accessibility access after the first launch.

## Use

1. Launch VoicePaste.
2. Hold the hotkey.
3. Speak, then release the key.

The transcript is inserted into the active app. Set the endpoint and API key in Settings.
