# VoicePaste

Press the hotkey, speak, release — VoicePaste inserts the transcript into the active field.

Download the macOS, Windows, or Linux installer from the [v2.0.0 release](https://github.com/megamen32/voicepaste-fn/releases/tag/v2.0.0). On macOS, allow Microphone and Accessibility access on first launch, then set the compatible Whisper endpoint and API key in Settings.

Test status: macOS Rust/Tauri production canary passed. Windows and Mac Mini were not tested in this session because their remote sessions were unavailable.
